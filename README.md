# PowerBi_Virat-Kohli_Statistics-
This is an Dashboard of Virat Kohli Carrier Analysis using Power BI.
-In this Dashboard analysis is done for all the three formats of cricket.
-It consists of different charts like Donat Chart, Clustered column Chart, Stacked area Chart which show different Runs Scored.
-This dashboard also includes Slicers, cards.
Using this dashboard analysis Virat Kohli Carrier becomes more easy.
